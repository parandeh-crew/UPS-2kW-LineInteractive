Finite State Machine (FSM) Design  ### 5.1 State Definitions  #### 5.1.1 INIT  - **Entry Action:** Power-on reset, initialize peripherals  - **Run Action:** Self-test sequence (ADC cal, relay test, buzzer beep)  - **Exit Action:** Prepare for next state  - **Timeout:** 5 seconds max  #### 5.1.2 STANDBY  - **Entry Action:** All outputs off, start monitoring  - **Run Action:** Read sensors, check conditions  - **Exit Action:** —  #### 5.1.3 NORMAL (LINE)  - **Entry Action:** Close bypass relay, start charger  - **Run Action:** Monitor AC input, regulate charger, update display  - **Exit Action:** Open bypass relay (at zero-cross)  #### 5.1.4 BATTERY (BACKUP)  - **Entry Action:** Start inverter soft-start, close inverter relay  - **Run Action:** Regulate output voltage, monitor battery, update display  - **Exit Action:** Ramp down inverter, open inverter relay  #### 5.1.5 FAULT  - **Entry Action:** Safe state: all PWM off, all relays open, buzzer alarm  - **Run Action:** Display fault code, log fault  - **Exit Action:** Clear fault flags (requires user ack)  #### 5.1.6 SHUTDOWN  - **Entry Action:** Graceful power-down sequence  - **Run Action:** Save logs, turn off all outputs  - **Exit Action:** Enter low-power mode or power off  ### 5.2 State Transition Table  | # | From | To | Guard Condition | Action | Priority |  |---|------|-----|-----------------|--------|----------|  | 1 | INIT | STANDBY | self_test_passed | — | 1 |  | 2 | STANDBY | NORMAL | ac_ok ∧ battery_ok | — | 1 |  | 3 | STANDBY | BATTERY | ac_fail ∧ battery_ok | — | 2 |  | 4 | STANDBY | FAULT | any_fault | — | 0 (highest) |  | 5 | NORMAL | BATTERY | ac_fail | open bypass, start inverter | 1 |  | 6 | NORMAL | FAULT | overload ∨ overtemp ∨ short | safe_state() | 0 |  | 7 | NORMAL | SHUTDOWN | power_btn_long | shutdown_seq() | 1 |  | 8 | BATTERY | NORMAL | ac_return ∧ sync_ok | sync, switch | 1 |  | 9 | BATTERY | FAULT | bat_empty ∨ overload | safe_state() | 0 |  | 10 | BATTERY | SHUTDOWN | power_btn_long | shutdown_seq() | 1 |  | 11 | FAULT | STANDBY | fault_cleared ∧ user_ack | clear flags | 1 |  | 12 | ANY | SHUTDOWN | critical_fault | emergency_off() | 0 |  ### 5.3 Sub-State Machines  #### 5.3.1 Charging State Machine (inside NORMAL)  ``` CC (Constant Current)  │  ▼  I_charge = 0.72A (0.1C)  │  ▼  V_batt reaches 54.0V ──► CV (Constant Voltage)  │  ▼  V_batt = 54.0V, I_charge decreases  │  ▼  I_charge < 0.05C (~0.36A) ──► FLOAT  │  ▼  V_batt = 52.8V, trickle charge  ```  #### 5.3.2 Inverter State Machine (inside BATTERY)  ``` SOFT_START  │  ▼  SPWM duty ramps from 0% to target over 5 cycles  │  ▼  V_out reaches 220V ──► STEADY_STATE  │  ▼  Closed-loop voltage regulation active  │  ▼  ac_return detected ──► SYNC  │  ▼  Phase/frequency sync with mains  │  ▼  sync_ok ──► switch to NORMAL  ```  #### 5.3.3 Fan State Machine (orthogonal)  ``` OFF  │  ▼  T > 35°C ──► LOW (30%)  │  ▼  T > 50°C ──► MEDIUM (70%)  │  ▼  T > 65°C ──► HIGH (100%)  │  ▼  T < 30°C ──► OFF  ```  ### 5.4 FSM Implementation Notes  > Describe the coding approach: function-pointer table, switch-case, or state pattern.  > Include pseudo-code for the state dispatcher.  ---  ## 6.
